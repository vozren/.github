# .github

Vozren（沃兹伦）组织的默认社区健康文件和组织主页配置。

Default community health files and organization profile for **Vozren**.

## 文件说明 · What's Inside

| 文件 | 用途 |
| --- | --- |
| `profile/README.md` | 组织主页展示内容（使命/愿景/价值观） |
| `CODE_OF_CONDUCT.md` | 社区行为准则 |
| `CONTRIBUTING.md` | 贡献指南 |
| `SECURITY.md` | 安全漏洞报告政策 |
| `SUPPORT.md` | 用户支持指引 |
| `FUNDING.yml` | 赞助渠道配置 |
| `ISSUE_TEMPLATE/` | Issue 模板（Bug 报告 / 功能请求） |
| `PULL_REQUEST_TEMPLATE.md` | PR 模板 |

## 生效范围 · How It Works

这些文件会自动应用到 `vozren` 组织下所有**没有单独定义**对应文件的仓库。

These files apply to all repositories under `vozren` that don't define their own.
